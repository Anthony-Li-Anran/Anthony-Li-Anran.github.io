<h2>欢迎来到我的留言板</h2>

<p>欢迎留言、分享想法、提问，或者只是打个招呼。无论你对我的研究感兴趣，对我的项目有反馈，还是只是想联系我，我很乐意听到你的声音。</p>

<h3>如何留言</h3>

<p>要留言，你需要一个 GitHub 账户。只需点击下方的讨论框，使用你的 GitHub 账户登录即可参与讨论。</p>

<p>评论由 <a href='https://giscus.app/' target='_blank'>giscus</a> 提供支持，并与 GitHub Discussions 同步。</p>
