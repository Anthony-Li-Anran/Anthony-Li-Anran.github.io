AutoSTAT is dedicated to becoming a copilot for users' data analysis. We are building an entry-friendly data analysis Agent framework that covers end-to-end data analysis workflows, can continuously optimize results through multi-turn interactions with users, and is capable of accommodating LLM technology iterations over the next five years, helping users efficiently advance every step of their analysis tasks.

## Features

### Full Workflow Coverage
Full workflow coverage with modular reconstruction of data analysis. AutoSTAT covers five processes: import, preprocessing, visualization, modeling, and report generation. Each process adopts a modular design with dedicated Agents responsible for tasks, seamlessly integrating Agent capabilities into data analysis.

### Code Generation
Write code to unleash data analysis potential. Coding supports both tool invocation and autonomous development. Agents can not only precisely understand user requirements and flexibly invoke existing tools, but also autonomously develop new tools based on needs, balancing stability and flexibility while accommodating future model capabilities.

### Automatic Mode
Automatic mode, let AI lead data analysis. Designed for beginners with simple, easy-to-use operations. Simply upload data and let the Agent handle the rest. Built-in Planning Agent automatically decomposes tasks and intelligently divides work for one-click generation of high-quality data analysis reports.

### Professional Reports
Professional reports, generate complete analysis with one click. Multi-Agent collaboration automatically generates an initial outline that users can flexibly adjust. The Report Agent outputs professional-grade data analysis reports with rich text and images from overview to details based on the final outline.

## Technology Stack

- **Language**: Python 3.9+
- **Framework**: Streamlit
- **AI Models**: Deepseek, ChatGPT, Tongyi Qianwen, Zhipu AI
- **Architecture**: Multi-Agent System
