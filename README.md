# Anthony-Li-Anran.io

This is Anthony Li's personal website.

## Live2D companion

The rebuilt Stelle model is enabled in `_config.yml` at
`assets/live2d/stelle-cubism-20260919/Stelle.model3.json`. It was opened, saved,
reopened and exported as SDK 4.2 using official Cubism Editor 5.3.04.

The fixed bottom-right chest portrait supports mouse tracking, blinking,
15 expressions and five native hair-physics chains. Physics is evaluated once
per frame after pointer/expression inputs. The companion pauses when hidden,
does not load on mobile, and defaults to hidden for reduced-motion preferences.
The greeting is a fixed line, with no AI service. Model source rules are retained
beside the runtime files; the editable CMO3 stays in the local delivery package.

The experimental AI chat, persona, inference worker, local AI libraries and
related status announcements have been removed.
